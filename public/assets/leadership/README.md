# Leadership Team Photographs

Place the official leadership team portrait photographs in this directory using the filenames below:

- `ramakrishna-s.webp` (Ramakrishna S — Founder)
- `warner-burzer.webp` (Warner Burzer — CTO)
- `jeff-mario.webp` (Jeff Mario — CRO)

### Format & Specifications:
- Preferred format: `.webp` (or `.jpg`/`.png` converted to webp).
- Target aspect ratio: 1:1 (Square).
- Recommended resolution: 320x320 px or 400x400 px.
- Proportions: Centered headshot portrait with clean/neutral background.
- Display styling: The website automatically applies `object-fit: cover` and smooth rounded corners.
- Automatic Fallback: If any photo file is missing, the application automatically displays an elegant, neutral photo placeholder icon without layout shift.
